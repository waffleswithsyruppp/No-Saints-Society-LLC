# NO SAINTS SOCIETY

Start with **SETUP.md**. This package is a dependency-free, white, minimalist storefront with a demo cart and a separate Shopify Storefront API adapter.

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

Add your own `nosaintssocietylogo.png` next to index.html. Generated clothing mockups and sample prices are for demonstration only. Live checkout is not connected.

Tests: `node --test tests/*.test.js` with Node.js 22+.
